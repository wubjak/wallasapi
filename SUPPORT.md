# Getting Support

Hi, I'm Willen Ponce — the sole maintainer of WallasAPI. Here's how to get help.

## 🐛 Found a bug?

Open an [issue on GitHub](https://github.com/wubjak/wallasapi/issues/new) with:

- What you tried to do
- What happened instead
- Your OS and Python version
- The traceback or error message

I read every single issue, even if I can't always reply immediately.

## ❓ Need help with usage?

1. Check the [interactive Swagger docs](http://localhost:8001/docs) once your server is running
2. Read the [README](README.md) — most questions are answered there
3. Open a [GitHub Discussion](https://github.com/wubjak/wallasapi/discussions) (or an issue tagged `question`)
