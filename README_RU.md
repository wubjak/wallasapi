## Почему Существует WallasAPI: История, Которая Имеет Значение

Я родился не с MacBook Pro M4. У меня нет облачных серверов, финансируемых инвесторами из Кремниевой долины. За мной нет команды из 50 инженеров. **У меня есть ноутбук 2018 года, съемная комната, которая мне не принадлежит, и одержимость: доказать, что из нужды можно построить что-то, конкурирующее с корпорациями.**

WallasAPI родился в украденных часах между беспокойством об аренде, о следующей еде, о возможности спать хотя бы четыре часа подряд, не просыпаясь с мыслями о долгах. У меня не было денег на дорогие API. За мной не стояла компания. У меня был только один одержимый вопрос:

> **"Почему я должен зависеть от одного поставщика ИИ, когда весь мир моделей снаружи, многие бесплатные, многие лучше для конкретных задач?"**

Так что я построил это. **Строка за строкой Python. Без роскошных фреймворков. Без команды. Без инвесторов.** Только чистый код, умные эвристики и отчаянная потребность создать что-то, что работает.

**WallasAPI — это не просто программное обеспечение. Это технологическое выживание.** Это роутер, который не берет с вас плату за ум. Это система, которая не бросает вас, когда падает OpenAI, когда истекает ваш ключ API Claude или когда ваш любимый провайдер решает повысить цены.

## Что Такое WallasAPI?

WallasAPI — это **унифицированный роутинг-движок**, который подключает ваше приложение, IDE или агента с **более чем 12 поставщиками ИИ** через **один API, полностью совместимый с OpenAI**.

Когда вы отправляете запрос, WallasAPI:
1. **Анализирует содержимое** (текст, изображение, аудио, PDF, видео)
2. **Выбирает оптимального провайдера** на основе возможностей, скорости, доступности и стоимости
3. **Автоматически маршрутизирует запрос**
4. **Если основной провайдер падает**, прозрачно переключается на следующий
5. **Возвращает ответ** в формате, совместимом с OpenAI, со стримингом при необходимости

**Ваш существующий код работает без изменений.** Просто измените базовый URL.

## Основные Возможности

- **Интеллектуальное Мульти-Провайдерное Роутинг с Автоматическим Фоллбеком**
- **Реальный Стриминг с Полной Прозрачностью**
- **Мультимодальная Поддержка** — Текст, изображения, аудио, видео, PDF
- **Богатые Метаданные** — Контекстное окно, ценовой уровень, инструменты, стриминг, модальности
- **Постоянная Память** — Локальная JSON-история, синхронизируемая с Obsidian
- **Унифицированная Генерация** — Изображение, видео, TTS от множества провайдеров
- **OCR с Цепочкой Фоллбека** — EasyOCR → Mistral → Gemini → Локальный Ollama
- **100% Приватные Локальные Модели** — Через Ollama
- **Полная Интеграция Google** — Drive, Calendar, Gmail с OAuth2

## API Эндпоинты

| Эндпоинт | Метод | Описание |
|---|---|---|
| `POST /v1/chat/completions` | Чат | Комплишены со стримингом. Виртуальные модели: `auto`, `fast`, `standard`, `reasoning`. |
| `POST /v1/embeddings` | Эмбеддинги | Мульти-провайдер роутинг. |
| `POST /v1/tts` | TTS | Текст в речь. |
| `POST /v1/images/generations` | Изображение | Унифицированная генерация изображений. |
| `POST /v1/videos/generations` | Видео | Унифицированная генерация видео. |
| `GET /v1/models` | Список | Модели с полными метаданными. Фильтры: `?pricing=free`, `?capability=vision`. |
| `GET /v1/models/{id}` | Детали | Подробные метаданные модели. |
| `GET /v1/capabilities/summary` | Сводка | Сколько бесплатных, с vision, аудио, reasoning и т.д. |
| `GET /v1/providers` | Провайдеры | Глобальные метаданные по провайдеру. |

## Быстрая Установка

### Windows (Рекомендуется: Двойной клик по `start.bat`)

```bash
git clone https://github.com/vash-username/wallasapi.git
cd wallasapi
# Двойной клик по start.bat
```

### Linux / macOS

```bash
git clone https://github.com/vash-username/wallasapi.git
cd wallasapi
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m wallasAPI.api_server
```

Сервер запускается на **http://localhost:8001**

Интерактивная документация: **http://localhost:8001/docs**
